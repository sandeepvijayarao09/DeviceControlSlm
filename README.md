# DeviceControlSlm

On-device **agentic Small Language Model (SLM)** for Apple devices — iPhone, iPad, and
MacBook — built on Apple's [MLX](https://github.com/ml-explore/mlx).

The goal: a compact model + runtime whose job is **agentic device control** — understand a
request, plan, call tools, and take real, safe actions on the device, entirely on-device
and private.

This is the baseline branch. Development lands via pull requests. See the active PR for the
architecture, roadmap, and the runnable agent core.
